sketchling — twelve loops

Twelve seamless clips, each one a TypeScript scene rendered by sketchling — a hand-drawn illustration and animation language. Nothing here was drawn by hand or edited in a timeline; every frame comes out of the source file beside it.

npm install -g sketchling github.com/AnayGarodia/sketchling scene sources how these twelve were chosen
Each clip is a 3.3s loop cut from its scene's own timeline, so it repeats without a seam. Regenerate everything with gallery/build.sh.
